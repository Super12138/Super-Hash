一个快速、随时可用，且遵循 Material Design 3 的跨平台文件校验器

本文档支持：<strong>中文（简体）</strong>| [English](README_EN.md)

## ✨ 功能

- 极小应用体积（桌面端安装包 ~3MB，网页端总资源 ~1MB）
- Material Design 3 设计系统
- Windows、macOS双系统+Web支持
- 自定义主题色
- 深色模式
- 校验和生成文件哈希（MD5、SHA）
- PWA（Progressive Web App，渐进式 Web 应用）
